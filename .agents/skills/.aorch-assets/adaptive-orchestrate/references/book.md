# Book work

Load the book project’s coordinator and the skill relevant to the current stage. Preserve its manuscript schema, source evidence, rights checks, digest-based QA and publication approval requirements. Draft or edit a small bounded passage directly when its context fits. Keep wording edits within their approved scope and report substantive concerns.

Run the project’s relevant checks on changed content; inspect changed or machine-flagged pages and CJK rendering when applicable. Full release QA belongs at the project’s release milestone. Independent editorial or acceptance review is useful when the change is uncertain, consequential or explicitly requested. `examples/plan-book-chapter.json` is an optional pipeline, not a required role count, provider pairing or model tier.
