# 모의 단타 안정화 검증 기록

범위는 [구현 계약](2026-09-14-paper-stabilization.md)과 [운영 절차](../paper_intraday_runbook.md)의 9월 14일 안정화 프로필이다. 기존 legacy 전략과 시험 위험 한도는 보존한다. 기능은 명시적으로 선택해야 켜진다.

## 현재 증거

- 전체 오프라인 검사: python scripts/verify-paper.py — 1,760 passed, 2 skipped. 이어지는 smoke 통과, broker=mock, live_trading_enabled=false, Level 5 operator blocked.
- 최종 전체 검사에는 독립 검토에서 추가된 주문·취소·월 기준·인수 시각 회귀 검사를 포함한다.
- tach check 통과. PowerShell 파서로 paper-runtime.ps1 구문 확인.
- 기존 Starlette/AnyIO의 deprecation warning 한 건. 건너뛴 외부 통합 검사를 실제 브로커 인수로 해석하지 않는다.
- Anthropic/Opus 최종 독립 검토: PASS, 재현 가능한 잔여 차단 사항 없음. 검토자가 별도로 실행한 통합·회귀 21개도 통과했다. 검토한 소스 해시와 현재 코드가 일치함을 확인했다.

## 실행 경계와 남은 인수

오프라인 검증 당시에는 실제 운영에 적용하지 않았다. 이후 사용자가 9월 14일 신규 진입 가동까지 승인하여 운영 의존성을 갱신하고, 기존 역할을 종료하고, 두 원장 백업·무결성 확인 후 정책 v5로 기능을 적용했다. 조회 전용 계좌 대사와 운영 가상환경의 관련 검사 38개가 통과했다. 기본 pytest 임시 경로의 권한 오류는 별도 검증 임시 디렉터리를 지정하여 해결했다. 이 운영 적용 단계에서는 commit·push·PR을 만들지 않았다.

현재 감독 프로세스 시작과 신규 진입은 KIS_PAPER_HTS_ID의 로컬 입력을 기다린다. 기존 위험 기준은 변경하지 않았다. 9월 15일 08:50 장전 준비 후 같은 스레드의 후속 실행을 09:03으로 갱신하여 장중 대사·실시간 시세·분봉·손실 한도·회복 검사를 확인하고, 통과할 때 해당 세션의 resume를 실행하도록 예약했다. 다른 거래일의 자동 재개 권한은 부여하지 않는다. 운영 상태와 가동 결과는 저장소 밖 시험 디렉터리에 보존한다. 실제 모의서버의 암호화 체결 통지와 네 개의 완전한 거래일은 아직 확인해야 하며, 단위 테스트의 가짜 입력은 그 증거를 대체하지 않는다.

독립 작업 영수증은 저장소 밖 ~/.codex/paper-stability-modules-result.json에 있다. supervisor 작업의 격리 환경에서는 지정 검사기의 임시 디렉터리 권한 때문에 partial을 보고했으며, 본 작업 환경에서 통합한 코드로 관련 검사와 전체 검사를 완료했다. 최종 구현은 위임 원본을 그대로 복사한 상태가 아니라 요청 예산·암호화 의존성·감독 실행기·원장 연결을 재검토하고 수정한 상태다.

## 독립 검토 첫 판정과 수정

Anthropic/Opus 독립 검토의 첫 판정은 BLOCK이었다. 전송되지 않은 취소 claim, 무효 종가에 종속된 일·월 기준, 청산 후 남는 장애 범위, 정상 재연결 뒤의 횟수 초기화, API 대기 실패의 전송 미상 오분류를 지적했다. 각각 재현 테스트를 추가하고 수정했다. 전송 경계가 직접 보증하는 BudgetNotSent만 취소 claim을 해제하며, 전송에 들어간 뒤의 timeout은 계속 결과 미상이다. 수정과 기존 안전 경계를 함께 검증한 30개 검사가 통과했다. 첫 검토의 공백 검사 오류도 수정했다.

통지 ACK 처리에서는 [한국투자 공식 system_resp](https://github.com/koreainvestment/open-trading-api/blob/main/examples_user/kis_auth.py)를 다시 확인했다. 공개 ACK의 암호 메타데이터는 계좌 복호화기에 사용하지 않고 무시한다. 계좌 ACK는 키·IV 길이를 검증하며 실제 통지는 계속 암호화된 H0STCNI9 형식만 허용한다. 실제 모의 프레임 확인은 운영 인수에 남는다.


## 최종 판정

오프라인 구현 준비 완료. 최종 검토 실행은 31c8e2b1-9fde-47a0-b5e8-105e62f7c461 / monthly-remedy-gate이며, 영수증은 ~/.codex/worktrees/qp-paper-stability-review/.aorch/task-runs 아래에 있다. 최종 전체 검사는 1,760 passed, 2 skipped, smoke 통과, tach 통과, 실행기 PowerShell 구문 및 git diff --check 통과다. 최종 소스 비교 목록은 ~/.codex/paper-stability-final-manifest.json에 보존했다.

두 번째 검토에서 드러난 월 기준 복구 부재는 운영자의 명시적 month-baseline 절차로 해결했다. 확인된 당일 종가와 보존된 현금, 빈 원장, 중지 상태, 정책 버전 및 검토 사유를 검사하고 네 역할 잠금을 잡는다. 일일 기준과 일 손실·낙폭 halt를 유지하며 baseline_override 감사를 남긴다. 해당 날짜를 포함한 인수 기간은 통과하지 않는다.

이 명령은 과거 월초 종가를 복원하지 않고 새 월 위험 측정 기간을 시작한다. 월 손실 검사는 재설정 이전 월간 손실을 더 이상 포함하지 않으므로, 운영자가 그 영향을 검토한 경우에만 사용한다. 현재 거래일의 확인된 종가가 필요하고, 잘못된 기존 디렉터리에 apply를 호출하면 기본 빈 원장 파일이 만들어질 수 있으므로 읽기 전용 미리보기로 대상을 먼저 확인한다. 실제 모의 스트림 프레임과 네 개의 완전한 거래일은 별도 운영 인수로 남는다.
