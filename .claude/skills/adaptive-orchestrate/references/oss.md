# Open-source reuse

Read the actual licence and inspect the code paths and dependencies relevant to the intended reuse. Record what can be reused, what must change, obligations and unresolved evidence. Add required notices in the same change that introduces reused material.

Use a researcher, analyst, licence reviewer or independent reviewer only where the evidence or risk benefits from a separate context. `examples/plan-oss-adoption.json` is an optional larger-work example; remove unnecessary stages. Do not infer a requirement for five workers or a different provider from that example.
