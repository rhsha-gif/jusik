# EXP-001 · 스윙 오버레이가 코어 보유에 가치를 더하는가

> 상태: **완료 (기각) — 단, 구현 한계로 재실험 필요**
> 사전등록: 2026-07-26 · 실행: 2026-07-26
> 시행 횟수 카운터: **이 실험이 1번째**

---

## 1. 사전등록 (실행 전 확정)

### 가설
논지로 고른 종목을 코어로 보유하면서, 일부 수량으로 **오르면 팔고 내리면 사는**
스윙 매매를 얹으면 코어만 보유하는 것보다 수익이 높아진다.

### 근거의 강도
**약함.** 사용자 진술: *"논리적으로 그럴듯해서."* 직접 운용 경험이나 문헌 근거 없음.

### 비교군
| | 구성 |
|---|---|
| **A** | 코어 100% — 매수 후 보유 (기준선) |
| **B** | 코어 70% + 스윙 30%, 국면 필터 없음 |
| **C** | 코어 70% + 스윙 30%, 200일 SMA 기울기가 우상향이면 스윙 **매도** 억제 |

### 판정 기준 (결과를 보기 전에 확정)
> **스윙 순기여(CAGR 차이)가 연 +2.0%p 이상이면 채택, 미만이면 기각.**

복잡도·비용·세금·운영부담을 감안한 최소선. 이보다 작으면 스윙을 만드는 값을 못 함.

### 파라미터 (1세트 고정, 탐색 금지)
```
기준가        SMA 20
밴드          기준가 ± 1.5 × ATR(14, Wilder)
스윙 슬롯     3분할 매수, 상단 터치 시 전량 매도
코어 비율     70%
국면 필터     SMA200[t] > SMA200[t-20]
워밍업        220 bars
체결          신호 다음 세션 시가 (look-ahead 없음)
```

### 비용 가정
```
수수료   IBKR Fixed: max($1.00, $0.005/주), 거래대금의 1% 상한
슬리피지 5 bps / 편도
양도세   22%, 연 $1,800 공제 (한국 거주자 해외주식), 이월결손금 없음
```

### 표본
- **30종목**, 성격별 균등 (고변동 성장주 10 / 저변동 방어주 10 / 횡보·경기민감주 10)
- **10년** (2016-07-25 ~ 2026-07-24), 종목당 2,514봉
- 분할·배당 조정 (`adjclose/close` 비율로 OHLC 일괄 조정)
- **사용자 실제 테마 종목이 아닌 대체 샘플** — 종목 선정 능력과 스윙 규칙의 가치를 분리하기 위함
- 종목당 $10,000을 독립 시뮬레이션 → 30개의 짝지은 관측치

## 2. 결과

### 판정: **기각**

| | 스윙 순기여 (연, 세후) | 코어를 이긴 종목 |
|---|---:|---:|
| B 필터 없음 | **−1.89%p** (중앙값) | 3 / 30 |
| C 필터 있음 | **−1.46%p** (중앙값) | 5 / 30 |

### 원인 귀속

| | B | C |
|---|---:|---:|
| 총 열세 | −1.89%p | −1.46%p |
| ├ 수수료·슬리피지·세금 | −0.03%p | −0.04%p |
| └ **추세 상실** | **−1.86%p** | **−1.42%p** |

**손실의 98%가 비용이 아니라 "오른 걸 팔아서 추세를 놓친 것".**
수수료를 0으로 만들어도 결과가 거의 바뀌지 않음.

### 세금
세전·세후 차이 **0.00%p**. 연 $1,800 공제 때문에 이 규모에서는 과세가 사실상 발생하지 않음.
→ 소액 단계에서 양도세를 설계 변수로 다룰 필요 없음이 확인됨.

### 버킷별
```
고변동 성장주       B -4.08%p   C -2.85%p     ← 가장 나쁨
저변동 방어주       B -1.62%p   C -1.21%p
횡보·경기민감주     B -1.44%p   C -1.32%p
```
사용자 테마(AI·전력·냉각)가 속하는 고변동 성장주에서 열세가 가장 큼.
**판단이 잘 맞을수록(크게 오를수록) 스윙이 더 크게 손해를 끼치는 구조.**

### 국면 필터의 효과
방향은 옳았음 — 순기여 개선(−1.89 → −1.46), 거래 횟수 급감(NVDA 126 → 32회).
추세 구간에서 매도를 억제해 코어를 지키는 의도대로 작동. **다만 부호를 뒤집지 못함.**

## 3. 이 결과를 그대로 믿으면 안 되는 이유 (구현 한계)

사용자 지적에 따라 재검토한 결과, **구현이 스윙에 불리하게 편향돼 있었음:**

1. **매수/매도 비대칭.** 매수는 3분할인데 매도는 스윙 보유 전량.
   진짜 그리드는 레벨별로 짝을 지어(−1에서 산 걸 0에서 매도) 작은 진동을 반복 수확함.
   현 구현은 큰 스윙 한 번에만 반응하므로 그리드의 핵심 이득을 못 냄.

2. **기준가가 움직임 (SMA20).** 이동평균은 추세를 따라 상승하므로,
   상승장에서 밴드가 계속 위로 이동해 매도 신호가 반복 발생.
   사용자가 의도한 *"오르면 팔고 내리면 사고"* 는 **고정 격자**에 가까움.
   → "추세 상실 98%"의 **일부는 그리드의 본질이지만 일부는 이 설계 선택의 산물.**

3. **국면 필터가 매도만 억제.** 추세 상승 중에도 매수는 계속되어 슬롯이 차 있음.

4. 코어를 시작일 일괄 매수로 단순화 (실제 계획은 신호마다 3~4회 분할).

### 결론의 유효 범위
> **"SMA20 기준 ±1.5ATR, 전량 매도 방식의 스윙 오버레이는 이 표본·이 기간에서 코어 보유를 이기지 못한다."**
>
> **"스윙 매매 일반이 무가치하다"로 확장 해석할 수 없음.**

## 4. 후속 (미실행)

재실험 시 바꿔야 할 것:
- 고정 격자 기준가 (진입가 또는 장기 앵커) + 레벨별 짝짓기 매도
- 국면 필터를 매수에도 적용
- 코어 분할 진입 반영

**주의:** 위 변경은 파라미터 탐색이 아니라 **구현 결함 수정**이지만,
새 결과는 시행 횟수 카운터의 2번째 항목이 됨. 판정 기준(+2.0%p)은 그대로 유지한다.
