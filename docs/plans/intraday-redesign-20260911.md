# 분봉 신호·틱 집행 재설계

사용자가 승인한 설계의 구현 기록. 기존 일봉 전략과 결과는 참고자료로 보존한다.

## 확정된 계약

- KRX 정규장 현금 매수, 당일 청산. 1분 원본, 5분 문맥, 틱/호가 집행.
- 500만 원 별도 실험. 거래당 비용 포함 손실 0.5%, 종목당 25%, 동시 2종목.
- 당일 시작 자산 대비 1% 손실이면 신규 진입 중단. 미체결 주문과 보유분의 계획 손실도 예약한다.
- 최고 자산 대비 5% 낙폭이면 원인 검토와 명시적 재개까지 중단. 재시작·전략 버전 변경으로 초기화하지 않는다.
- 거래량 동반 돌파, 상승 추세 눌림 회복, 장중 과잉 반응 후 기준가 회귀의 세 가설과 작은 탐색 범위를 사전에 고정한다.
- LLM은 검증된 규칙의 전략 예산만 0.8–1.2배 조정한다. 30분 정기 갱신과 사전 정의된 변동 이벤트, 이벤트 간 최소 10분. 실패·지연·만료 시 규칙으로 복귀한다.
- 모의 시세 API 우선. 무료 외부 이력은 출처·이용 조건·품질을 확인한 뒤 사용한다. 유료 데이터나 실전 시세 API로 자동 전환하지 않는다.
- 데이터는 발생·수신·이용 가능 시각, 당시 유니버스와 제외 이유, 출처와 해시를 보존한다. 누락 봉을 합성하지 않는다.
- 시간순 학습 90거래일, 선택 30거래일, 봉인 검증 최소 60거래일. 전략별 검증 완료 왕복 거래 최소 100회.
- 수수료·세금과 편도 슬리피지 5/10bps 모두 비용 차감 후 양수. 지연·미체결·갭·부분체결 민감도 별도 보고.
- 거래일 블록 불확실성, 전체 탐색 이력과 반복 관찰 보정을 적용한다. 기본 전체 유의수준 0.05.
- 버전 고정 후 주문 없는 실시간 관찰 최소 20거래일. 통과한 버전만 paper_eligible. 자격 부여는 주문 활성화가 아니다.

## 구현과 검증 기록

- 시작 상태: 작업 트리 변경 없음, HEAD a0b8b63.
- 일봉 자료는 현재 단타 성과의 증거로 사용하지 않는다. 기존 분봉 저장소는 조사 당시 0개 봉이었다.
- 구현됨: 수집 원장, 인과적 전략/재현, 검증 상태 판정, 기존 주문 경로의 위험 한도와 연결. 독립 수정 검토 PASS, 전체 1,548개 테스트·모의 스모크·tach 검증 통과. 실데이터 자격 판정은 보류.
- 실데이터 검증과 실시간 20거래일 관찰은 fixture 테스트와 구분하여 결과를 기록한다.
- commit/push/PR 및 실제 주문은 이 작업의 실행 대상에 포함되지 않는다.
